# Schichtplan Automatiesierung 
Eine Automatisierung die einen Schichtplan der per Google Sheet Datei kommt Automatisch in einen Kalender einträgt.

## Problem
Viele Menschen bekommen Ihren Schichtplan als Excel oder Google Docs Datei, dieser ist sehr unübersichtlich und nicht mit anderen Terminen im Kalender verbunden. Der manuelle Übertrag in den Kalender kostet unötige Zeit und kann zu Fehlern führen. 

## Ziel 
Das Ziel ist eine Automatiesierung die Automatisch anhand der Schichtplan Datei alle Eintragungen aus dem Namen des Nutzeres übernimmt und Automatisch die Arbeitstage in der Kalender einträgt. 

## Geplante Tools
- n8n
- Google Sheets
